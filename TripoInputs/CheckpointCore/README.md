## Style lock

- Warm ivory casing, saturated orange armor and trim, mint-green secondary panels.
- Charcoal only for mechanical insets; cyan-blue for active energy / hover parts; warm yellow utility lights.
- Friendly chunky proportions, round corners, thin dark seams and light paint wear.
- Keep generated models as a single object with no environment, text, decals or characters.

For Tripo, start from the supplied image, preserve the overall silhouette and color blocking, enable PBR textures, then use the suggested asset name for the exported GLB/FBX.
