## Shared style lock

- Main casing: warm ivory. Structural guards: saturated orange. Secondary panels: mint green.
- Mechanical areas: graphite. Active energy: cyan. Service lights: warm yellow.
- Keep models as individual PBR props with clean, reusable silhouettes. Remove generated background planes, no text or logos.
