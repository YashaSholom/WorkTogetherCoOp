# Document Terminal Variations

Five isolated reference images for creating game-ready document-placement and inspection terminals in Tripo.

| File | Concept | Best placement |
| --- | --- | --- |
| `01-counter-document-terminal.png` | Shallow semicircle counter with five document bays and central scan slot | Main inspection desks |
| `02-vertical-intake-pillar.png` | Compact upright intake pillar with stacked feed drawers | Queue edges and narrow lanes |
| `03-circular-group-terminal.png` | Six-way collaborative sorting hub with central dome scanner | Open checkpoint hubs |
| `04-wall-document-station.png` | Wall-mounted four-slot scanner module | Corridors and small booths |
| `05-document-verification-booth.png` | Semi-enclosed premium verification counter | VIP / alien-specific lanes |

## Shared visual language

- Warm ivory shells with orange safety armor
- Mint / teal inset panels and graphite mechanical recesses
- Cyan interaction lighting with small warm utility lights
- Chunky, friendly spaceport construction: dark seams, rounded corners, bolts and mild edge wear

All artwork is deliberately isolated on a white studio backdrop so it is easier to use as an image-to-3D reference.
