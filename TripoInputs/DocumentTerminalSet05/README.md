# Document Terminal Set 05

Eight distinct document-placement terminal reference images for Tripo. Every terminal has a deliberately blank screen: no text, icon, logo or interface graphic.

| File | Terminal type | Suggested scene use |
| --- | --- | --- |
| `01-compact-single-user-terminal.png` | Narrow three-tray walk-up terminal | Short queue lanes |
| `02-two-sided-queue-terminal.png` | Double-sided central pillar | Two-sided waiting areas |
| `03-heavy-cargo-document-terminal.png` | Rugged five-slot customs station | Cargo inspection |
| `04-articulated-arm-terminal.png` | Mechanical-arm display with tray carousel | Maintenance / premium inspection |
| `05-document-mailbox-terminal.png` | Tall cabinet-style intake terminal | Self-service walls |
| `06-seated-service-desk-terminal.png` | Low curved desk console | Staff-operated counters |
| `07-high-security-arch-terminal.png` | Shielded standing terminal | Restricted lanes |
| `08-alien-accessible-terminal.png` | Wide radial multi-height terminal | Mixed-species access zone |

## Art direction lock

Warm ivory shells, mint inset panels, orange safety armor, graphite mechanical recesses, cyan interaction lights, rounded construction, thin dark seams and restrained edge wear. Each image is isolated on a white studio background for image-to-3D work.
