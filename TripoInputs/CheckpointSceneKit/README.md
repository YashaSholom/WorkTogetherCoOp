## Style lock

- Warm ivory as the main casing; orange for structural guards; mint for secondary panels.
- Charcoal for moving/mechanical surfaces; cyan for active energy; warm yellow for service lamps.
- Chunky rounded geometry, thin dark panel seams and only light paint wear.
- Generate each as one isolated PBR object: no ground, scene, characters, text or decals.
