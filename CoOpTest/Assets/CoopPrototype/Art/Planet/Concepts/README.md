## Proposed co-op layout to validate

The new concepts propose one shared incoming road from the portal, a fork into three independently openable vehicle lanes, then a shared exit route. Each lane owns an open-front checkpoint booth, visitor-facing decision terminal, vehicle stop pad and barrier. The back/central plaza is shared by the entire team: cargo X-ray, stash, upgrades, tools and a large event board readable from all stations. This is a layout proposal only; it has not yet replaced the current playable checkpoint scene.

## Mandatory-gate revision

The previous “three-lane” proposal was corrected after review: a vehicle must never be able to bypass inspection. The accepted traffic invariant is now **portal → one shared arrival road → one of exactly three enclosed inspection gates → shared exit road**. Every inspection gate has an entry barrier, a stop bay, a visitor-facing decision terminal and a rear exit barrier. There is no vehicle route from entry to exit outside those gates.

## Open-deck underpass revision

The mandatory-gate revision was further refined after layout review. The visitor-facing traffic is now **portal → one of three adjacent stop pads → rear ramp down below the shared station deck**. There is no surface exit road around or in front of the stations. The three pads belong to a single large connected staff deck under one continuous roof: no player walls, dividers, bridge segments or isolated station islands. The hub, holding cells, rest area and equipment all remain on that shared deck.
